## Описание страниц приложения

### 1. Страница «Лента» (`/biochemical-indicator/feed`)
Вертикальная прокрутка (TikTok-style) с эффектом бесконечной (закольцованной) ленты.
*   **Поля:**
    *   Фоновое видео (если есть `videoUrl`), иначе изображение (если есть `imageUrl`), иначе изображение-заглушка.
    *   Заголовок показателя.
    *   Описание — обрезается до 2 строк.
    *   Блок с диапазонами: «Макс.» (верхняя граница) и «Мин.» (нижняя граница).
    *   Счетчик лайков.
*   **Кнопки:**
    *   **«Еще» / «Свернуть»** — переключает отображение полного текста описания.
    *   **«Нравится»** — ставит/убирает лайк (меняет цвет иконки и счетчик). Доступна только авторизованному пользователю.
    *   **«Следующий»** — программно прокручивает ленту к следующей карточке.

### 2. Страница «Плитка» (`/biochemical-indicator/grid`)
Сетка карточек с возможностью фильтрации по значению.
*   **Поля:**
    *   Слайдер выбора значения (от 0 до 5000 ед.).
    *   Изображение на карточке (или заглушка, если `imageUrl` пуст).
    *   Заголовок, диапазон показаний (`min`-`max`).
    *   Счетчик лайков.
*   **Кнопки:**
    *   **«Поиск»** — применяет фильтр (оставляет карточки, в диапазон `min`-`max` которых попадает значение слайдера). Фильтр хранится в Redux и добавляется в запрос к бэкенду (`?value=`).
    *   **«Нравится»** — ставит/убирает лайк. Доступна только авторизованному пользователю.
    *   **«Подробнее»** — переход к карточке в ленте.
    *   **«Удалить»** — удаляет карточку (запрос к бэкенду). Доступна только авторизованному пользователю.

### 3. Страница «Добавление» (`/biochemical-indicator/draft`)
Форма создания новой карточки показателя. Создание выполняется через redux-thunk (`createIndicator`). В нижней навигации доступна только авторизованному пользователю.

### 4. Страница «Вход» (`/user/login`)
Форма авторизации. Авторизация выполняется напрямую через axios (без кодогенерации и thunk), состояние вручную передается в Redux; JWT хранится в `localStorage`. После входа в нижней навигации пункт «Вход» заменяется на «Выход».

## Нижняя навигация (Navbar)
Панель навигации состоит из 4 пунктов:
1.  **«Лента»** — доступна, ведет на `/biochemical-indicator/feed`.
2.  **«Добавить»** — доступна только авторизованному пользователю, ведет на `/biochemical-indicator/draft` (для гостя визуально заблокирована).
3.  **«Плитка»** — доступна, ведет на `/biochemical-indicator/grid`.
4.  **«Вход» / «Выход»** — для гостя ведет на `/user/login`; после авторизации показывает «Выход» (запрос к бэкенду, сброс фильтра и состояния гостя).
