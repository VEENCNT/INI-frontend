## Описание страниц приложения

### 1. Страница «Лента» (`/biochemical-indicator/feed`)
Вертикальная прокрутка (TikTok-style) с эффектом бесконечной (закольцованной) ленты.
*   **Поля:**
    *   Фоновое видео (если есть `videoUrl`), иначе изображение (если есть `imageUrl`), иначе изображение-заглушка.
    *   Заголовок показателя.
    *   Описание — обрезается до 2 строк.
    *   Блок с диапазонами: «Макс.» (верхняя граница) и «Мин.» (нижняя граница).
    *   Счетчик лайков.
*   **Кнопки:**
    *   **«Еще» / «Свернуть»** — переключает отображение полного текста описания.
    *   **«Нравится»** — ставит/убирает лайк (меняет цвет иконки и счетчик).
    *   **«Следующий»** — программно прокручивает ленту к следующей карточке.

### 2. Страница «Плитка» (`/biochemical-indicator/grid`)
Сетка карточек с возможностью фильтрации по значению.
*   **Поля:**
    *   Слайдер выбора значения (от 0 до 5000 ед.).
    *   Изображение на карточке (или заглушка, если `imageUrl` пуст).
    *   Заголовок, диапазон показаний (`min`-`max`).
    *   Счетчик лайков.
*   **Кнопки:**
    *   **«Поиск»** — применяет фильтр (оставляет карточки, в диапазон `min-max` которых попадает значение слайдера).
    *   **«Нравится»** — ставит/убирает лайк.
    *   **«Подробнее»** — кнопка для перехода к деталям (заглушка).
    *   **«Удалить»** — удаляет карточку из текущего состояния списка.

### 3. Страница «Добавление» (`/biochemical-indicator/draft`)
Форма создания новой карточки показателя. *(Недоступна из нижней навигации)*

### 4. Страница «Вход» (`/user/login`)
Форма авторизации. *(Недоступна из нижней навигации)*

---

## Нижняя навигация (Navbar)
Панель навигации состоит из 4 пунктов:
1.  **«Лента»** — доступна, ведет на `/biochemical-indicator/feed`.
2.  **«Добавить»** — недоступна (визуально заблокирована).
3.  **«Плитка»** — доступна, ведет на `/biochemical-indicator/grid`.
4.  **«Вход»** — недоступна (визуально заблокирована).
